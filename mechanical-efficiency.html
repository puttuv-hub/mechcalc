Understanding Mechanical Efficiency

Mechanical efficiency compares the useful mechanical power obtained from a machine with the mechanical power supplied to it.

The basic relationship is: η = Pout / Pin

  • 100% efficiency: output power equals input power.
  • Less than 100%: some input power is lost through friction, heat, vibration and other losses.
  • Higher efficiency: less input power is required for the same useful output.

For a real machine operating normally, useful output power cannot exceed the supplied input power.
